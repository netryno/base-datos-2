Colección asignatura

El profesor es un documento embebido y los inscritos un arreglo de referencias al _id del alumno. 

{
  _id: ObjectId,
  gestion: "2026",
  codigo: "BD2",
  nombre: "Base de Datos II",
  descripcion: "...",
  profesor: { dni, nombre, especialidad },
  inscritos: [
    { alumno_id: ObjectId, fecha_inscripcion: Date }
  ]
}
